# Gemini 画像生成プロンプト集（LINEビジュアル）

## ブランドカラー
- 金（真鍮）：`#C9A24B`（LP・動画と共通のブランドアクセント）
- 墨黒（LP用ダーク）：`#14110C`
- LINE用・明るいパレット：クリーム `#F7F1E3` ／ キャメル〜ベージュ ／ ティール差し色 `#5FB6A8` ／ 琥珀のあたたかい光

## キャラクター方針
**フクロウ（覚醒の象徴）**。夜に覚醒し、闇の中で見逃される価値を見抜く＝「眠る価値を覚醒させる」コンセプトに直結。金の音叉（チューニングフォーク）を持たせる。

---

## ① アイコン（顔アップ・明るい版・推奨）
```
LINEアイコン用のマスコットキャラクターを作ってください。賢く優しい表情の、ふっくらと丸いフクロウ。あたたかいクリーム色（#F7F1E3）の明るい背景の中央に、顔と上半身を大きく配置。羽はやわらかなキャメル〜ベージュで、目のまわり・くちばし・胸元の模様に金色（#C9A24B）のアクセント。大きな瞳には、朝日が差すような琥珀色のあたたかい光が灯る。差し色に爽やかなティール（#5FB6A8）を少しだけ。明るく親しみやすいけれど上品、フラットで洗練されたイラストレーション、やわらかな質感、文字なし、正方形（1:1）。
```

## アイコン・バリエーション
**A. 音叉を持つ全身版（カバー/スタンプ向き）**
```
明るく親しみやすいフクロウのマスコット。片方の翼で金色（#C9A24B）の音叉をそっと掲げ、先端から琥珀色のあたたかい光が"覚醒"するように灯る。あたたかいクリーム色（#F7F1E3）の背景、キャメル〜ベージュの羽、ティール（#5FB6A8）の差し色、明るく上品で洗練されたフラットイラスト、やわらかな質感、文字なし。横長（16:9）。
```
**B. ポップで可愛く**
```
かわいくて明るいフクロウのキャラクター、少し首をかしげた優しい笑顔。パステル調のあたたかいクリーム背景に、キャメルの羽と金色・ティールのアクセント、大きな瞳にきらめく光。丸みのあるポップで親しみやすいマスコット、文字なし、正方形（1:1）。
```
**C. 朝焼けグラデ**
```
上品なフクロウのマスコット。朝焼けのようなあたたかいグラデーション背景（クリーム〜淡いピーチ〜やわらかな金）。キャメルの羽に金のアクセント、瞳に琥珀の光。明るく希望に満ちた雰囲気、洗練されたフラットイラスト、文字なし、正方形（1:1）。
```

## ② LINEホーム背景（カバー）
推奨サイズ **1080×878 px（横やや長め）**。下〜中央はアカウント名/アイコンが重なるため余白を空ける。

**推奨**
```
LINE公式アカウントのホーム背景画像を作ってください。横長（おおよそ1080×878の比率）。あたたかいクリーム色（#F7F1E3）を基調にした明るくやわらかな背景。画面の上寄り・左寄りに、賢く優しい表情のふっくらしたフクロウのキャラクターを配置し、片方の翼で金色（#C9A24B）の音叉をそっと掲げ、その先端から琥珀色のあたたかい光が"覚醒"するように灯っている。羽はキャメル〜ベージュ、差し色に爽やかなティール（#5FB6A8）。画面の下半分と中央はシンプルな余白（あとからアカウント名やアイコンを重ねるため、文字や細かい要素を入れない）。明るく上品で洗練されたフラットイラスト、やわらかな光、繊細な質感、文字は一切入れない。
```
**A. キャラ控えめ・世界観重視**
```
LINEのホーム背景、横長。あたたかいクリーム〜淡いピーチの朝焼けのようなグラデーション背景に、小さめのフクロウと金色の音叉を右上にさりげなく配置。先端に琥珀色の光。下半分は広い余白。ミニマルで上品、希望に満ちた明るい雰囲気、文字なし。
```
**B. パターン／テクスチャ**
```
LINEのホーム背景、横長。クリーム色（#F7F1E3）の地に、金色（#C9A24B）の細い音叉のラインアートと、やわらかな光の波紋を規則的に散らした上品なパターン。とても淡く控えめ、たっぷりの余白、洗練された高級感、文字なし。
```

> コツ：アイコンと背景で同じキャラ・同じ配色に揃えると一気にプロっぽくなる。生成後に「もっと明るく／フクロウを左上に／下半分をシンプルに」で微調整。
