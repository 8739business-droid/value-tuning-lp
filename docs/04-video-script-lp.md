# LP本編動画 台本（約85秒）

**狙い**：冒頭3秒で「自分のことだ」と刺し、感情を動かしてLINE登録まで運ぶ。
**BGM**：前半=低く沈むドローン → 反転点で一拍の無音 → 後半=温かいピアノ/弦。
**構成**：痛み → 気づき → 共感 → 登録。前半は寒色、後半は暖色にトーンを切り替える。

## 演出メモ
- **冒頭6秒が命**：テロップ「値下げ、もう限界では？」は声より先に。音声OFF対策で全編テロップ必須。
- **④の暗転＋無音**が"視点反転"のスイッチ。前後でトーン（寒色→暖色）をはっきり切り替える。
- **世界観は前半で出さない**：⑦まで「価値調律」の言葉を伏せ、痛みと論理で引っ張る（"ねじれ"を動画でも踏襲）。
- 縦型9:16（META/リール）でも書き出し。LP埋め込み版は16:9トリミング。
