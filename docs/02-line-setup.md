# LINE公式アカウント 設計一式

## アカウント名（確定）
```
まさ｜価値調律で選ばれる店づくり
```
（16字／20字制限内）人（まさ）＋ブランド（価値調律）＋結果（選ばれる店づくり）。個人名で「人として売る」方針。

---

## ステータスメッセージ / 紹介文

短い一行用：
```
価値調律で、選ばれる店づくり。値段でなく"共感"で選ばれる店へ。
```

紹介文（長め欄）：
```
売上を、値下げで削らない。お店に眠る価値を"調律"し、値段ではなく
世界観・共感で選ばれる店づくりを伴走しています。
まずは無料特典「7つの問い」から。―まさ
```

## 特典「7つの問い」本文（教育0本目）
1. お客様は本当は「何」を買いに来ていますか？（商品ではなく、その奥にある"感情の変化"）
2. あなたの店を選んだお客様が、最後にくれた言葉は？
3. 値段を一切言わずにあなたの店を紹介するなら、何と言いますか？
4. 採算度外視でも、つい力を入れてしまうことは？
5. 他店ではなく"あなた"が選ばれる理由を、3つ挙げられますか？
6. 価格を2割上げても通ってくれるお客様は、何に価値を感じている？
7. 「この店がなくなったら困る」と言ってくれる人は、誰ですか？

## リッチメニュー構成

**おすすめ：6分割（2×3）**
```
┌─────────┬─────────┬─────────┐
│ ① 7つの問い  │ ② 動画を見る │ ③ まさって誰?│
├─────────┼─────────┼─────────┤
│ ④ お客様の声 │ ⑤ 個別相談   │ ⑥ 公式LP    │
└─────────┴─────────┴─────────┘
```

| # | ラベル | 役割 | リンク先 |
|---|---|---|---|
| ① | 7つの問い | 特典を再送 | 自動応答メッセージ |
| ② | 動画を見る | 教育①〜⑤ | 動画URL/リッチメッセージ |
| ③ | まさって誰？ | 自己紹介 | テキスト/note等 |
| ④ | お客様の声 | 実績・感想 | 実績ページ/画像 |
| ⑤ | 個別相談 | バックエンド導線 | 予約フォーム |
| ⑥ | 公式LP | 世界観の再確認 | LPのURL |

**シンプル版（横1×3）**：`① 7つの問い ｜ ② 動画 ｜ ③ 個別相談` から始め、反応を見て6分割に拡張。
